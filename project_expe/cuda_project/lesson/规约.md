
# ✅ 英文：**Reduction**（名词），动词 reduce

CUDA / 并行计算里：**Reduction = 规约（也常写作归约）**

> 论文、NVIDIA官方中文文档、NCCL集合通信，大多写作 **规约**；很多国内博客、教材写作 **归约**，读音完全一样：guī yuē。

## 一、字面含义：Reduction

英文本义：减少、缩减、降低。
在并行计算：**把一组多个元素，按照同一个二元运算（+ / max / min / and）不断合并，数据规模逐步缩减，最后得到少数值（通常是1个标量）**。
例子：数组全部求和、求全局最大值，都是 Reduction。

## 二、为什么翻译成「规约」？（重点）

> 两个汉字：**规 + 约**

1. **约**：对应 reduce 的“缩减”含义，数量变少，规模收缩。
2. **规**：代表**规则、规范**。
   规约操作不是随便合并，必须**遵守固定的二元运算规则**（满足结合律），所有线程/进程使用同一个运算来合并数据，是一种规范化的聚合操作。

> 对比「归约」：**归** 偏向“归拢、汇总”，只强调把数据收拢在一起，没有突出操作必须遵守统一数学规则。

### 历史小背景

“规约”这个术语，最早其实来自编译原理：**移进-规约（shift-reduce）**，LR语法分析里就用规约，表示按照产生式规则把多个符号归并成一个非终结符，同样是**按规则合并**。
后来并行计算、CUDA、MPI/NCCL 沿用了这个译法，`Reduce / AllReduce` 统一叫**规约**。

## 三、一句话定义 CUDA 规约

并行规约（parallel reduction）：**多个线程各自持有一个数值，按照同一个运算，逐层合并，不断缩减数据量，最终得到一个全局结果**。
树形合并：

```
[1, 2, 3, 4]
→ 1+2，3+4
→ 3 + 7
→ 10
```

CUDA规约就是利用SIMT多线程，并行完成这棵归并树。

## 四、相关名词

- Reduce：规约
- AllReduce：全规约（所有线程/进程最后都拿到最终结果，NCCL最常用）
- Reduce-scatter：规约-分散

## 五、容易混淆区分

1. **规约 Reduction**：多输入 → 少量输出（求和、max）
2. **扫描 Scan（前缀和）**：多输入 → 同样多输出（每一步中间结果全部保留）
